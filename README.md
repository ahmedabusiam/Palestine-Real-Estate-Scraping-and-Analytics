# Palestine-Real-Estate-Scraping-and-Analytics
مشروع (End-to-End) متكامل لاستخراج بيانات العقارات بفلسطين تلقائياً من الويب عبر Python وSelenium وحفظها بملفات CSV. يتضمن تنظيف البيانات وهندستها كتحويل العملات والمساحات، ومعالجة القيم الشاذة والمفقودة. يشمل تطبيق مصفوفة الارتباط وتقنية PCA لتقليل الأبعاد ، ثم بناء نماذج ذكاء اصطناعي متطورة للتصنيف والانحدار للتنبؤ بنوع العقار وسعره بدقة عالية
