## ⚙️ أقسام المشروع التفصيلية

### 1️⃣ القسم الأول: جمع البيانات من الموقع (Web Scraping)
[cite_start]الخطوة الأولى بدأت بتثبيت المكتبات الأساسية المطلوبة للعملية[cite: 5, 6]:
```bash
pip install selenium pandas
```
### تم بناء سكريبت متطور لجمع روابط الإعلانات عبر صفحات متعددة، واستخراج تفاصيل كل إعلان تشمل: (نوع العقار، السعر، المدينة، المنطقة، والمساحة)، مع دعم النقر التلقائي لتحميل السعر المخفي ورقم المعلن.  
#### التقنيات المستخدمة: تم استخدام Selenium مع متصفح خفي Google Chrome headless لتصفح الصفحات تلقائياً، والاعتماد على WebDriverWait لضمان تحميل عناصر الصفحة بالكامل قبل استخلاص البيانات.  
#### المخرجات: تم حفظ البيانات المستخرجة في ملف صيغة CSV عبر الأمر التالي:
```bash
df.to_csv("Palestine_real_estate_scraping_output.csv", index=False)
```
2️⃣##  القسم الثاني: تنظيف البيانات (Data Cleaning)
### بعد تحميل الملف البيئي إلى بيئة Google Colab، بدأت مرحلة تنظيف وتوحيد البيانات لرفع جودتها:  
#### توحيد العملة: تحويل جميع الأسعار المختلفة إلى عملة الدولار الأمريكي بناءً على تحويلات دقيقة من الشيكل والدينار.  
#### توحيد المقاييس: تنظيف حقول المساحات وتحويلها من وحدة (الدونم) إلى (المتر المربع).  
#### هيكلة البيانات النصية: توحيد تصنيفات نوع العقار في فئات واضحة ومحددة (مثل: شقة، أرض، بيت مستقل، إلخ...).  
#### تنسيق الاتصال: تعديل أرقام الهواتف لتتبع نسقاً واحداً يبدأ بـ 05.  
#### الزمن: تحويل التواريخ إلى صيغة datetime المدعومة برمجياً.  
#### معالجة القيم المفقودة: التحقق من الحقول الفارغة وتعويضها نسبياً باستخدام المتوسط الحسابي:
```bash
df.fillna(df.mean(numeric_only=True), inplace=True)
```
3️⃣##  القسم الثالث: المعالجة المسبقة (Data Preprocessing)
### تجهيز البيانات المدخلة لتصبح متوافقة مع النماذج الرياضية لخوارزميات التعلم الآلي:  
#### التطبيع (Normalization): تطبيع حقول المساحة والسعر باستخدام أداة MinMaxScaler لتوحيد النطاقات.  
#### القيم الشاذة: إزالة القيم الشاذة والمؤثرة سلباً (Outliers) بالاعتماد على خوارزمية النطاق الربيعي IQR.  
#### الترميز (Encoding): تحويل الأعمدة النصية (مثل المدينة ونوع العقار) إلى قيم رقمية باستخدام LabelEncoder.
#### تصفية الميزات: حذف الأعمدة غير المفيدة لتحليل النماذج مثل خانات "الوصف" و"الملاحظات".
## 4️⃣ : النمذجة - التصنيف (Classification)
### الهدف: التنبؤ بـ "نوع العقار" استناداً إلى مساحته والمدينة المتواجد بها.  
#### الخوارزميات المستخدمة:  
##### Logistic Regression
 ##### Random Forest Classifier  
 #### Support Vector Machine (SVM)
### مقاييس تقييم الأداء : الدقة (Accuracy)، الاستدعاء (Recall)، و F1 Score، مع إجراء مقارنة شاملة وعرضها برسم بياني عبر مخططات الأعمدة. 
## 5️⃣ النمذجة - الانحدار (Regression)
### الهدف: التنبؤ بقيمة "سعر العقار" بناءً على (المساحة، المدينة، ونوع العقار).   
### الخوارزميات المستخدمة:   
#### Linear Regression    
#### Random Forest Regressor   
#### Support Vector Regressor (SVR)   
#### XGBoost   
### مقاييس تقييم الأداء : تم التقييم وحساب نسبة الخطأ باستخدام مقاييس MSE و MAE و R2 Score ورسم النتائج لمقارنة الفروقات.   
## 6️⃣ القسم السادس: تقنيات تقليل الأبعاد (PCA) 
### بهدف تقليل التعقيد الحسابي وتحسين كفاءة النماذج، تم تطبيق تقنية PCA (Principal Component Analysis) للحفاظ على 95% من تباين البيانات.
### تمت مقارنة الأداء قبل وبعد تطبيق PCA على خوارزميات:   
#### Linear Regression   
#### Random Forest Regressor    
### 💡 النتيجة: أظهرت المقارنة أن PCA حسّنت من أداء بعض النماذج بينما أثرت سلباً على نماذج أخرى، بناءً على طبيعة وتوزيع البيانات.  
## 7️⃣ القسم السابع: تحليل الارتباط  (Feature Correlation)
### تم استخدام مصفوفة الارتباط (Correlation Matrix) لاكتشاف العلاقات القوية والميزات التي ترتبط بشدة ببعضها البعض بنسبة أعلى من (0.85). بناءً على ذلك، تم حذف الميزات المتكررة للحفاظ على تنوع البيانات ومنع حدوث التكرار الخطي المتعدد (Multicollinearity).
